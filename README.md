# sss-godot-framework
Документация: 2D-персонаж для Godot 4.6

Общая информация

Этот скрипт управляет 2D-персонажем с платформенной механикой. Персонаж может ходить, прыгать и реагировать на физику гравитации.

---

Переменные (объявлены вне скрипта)

maxSpeed:float-Максимальная скорость бега
minSpeed:float-Минимальная скорость при ходьбе
accTime:float-Время разгона до максимальной скорости
dragTime:float-Время торможения при остановке
skidTime:float-Время заноса при смене направления
jumpVel:float-Начальная скорость прыжка
addedJumpVel:float-Дополнительная скорость при удержании прыжка
gravAcc:float-Ускорение свободного падения
gravVec:Vector2-Вектор гравитации (обычно (0, 1))
jumpActionCount:int-Счётчик действий прыжка (0 - можно прыгать, 1 - прыжок выполнен)
fallState:bool-Состояние падения
dir:float-Направление движения (-1, 0, 1)
currentSpeed:float-Текущая скорость персонажа
_facing:float-Направление взгляда (-1 влево, 1 вправо)
velocity:Vector2-Вектор скорости персонажа
floor_angle:float-Угол наклона поверхности

---

Основные функции

_physics_process(delta: float) -> void

Главная функция, вызывается каждый физический кадр.

Параметры:

· delta-время между кадрами

Что делает:

1. Применяет гравитацию
2. Проверяет, на земле ли персонаж
3. Обнуляет счётчик прыжков при касании земли
4. Обрабатывает прыжок
5. Получает ввод с клавиш A/D или стрелок
6. Рассчитывает ускорение, торможение и занос
7. Поворачивает спрайт
8. Применяет движение
9. Выполняет перемещение с коллизиями

---

movement_aportunity()

Управляет физикой движения персонажа.

Логика работы:

1. Движение в одну сторону:
   · Если нажата клавиша и персонаж движется в ту же сторону
   · Скорость увеличивается от minSpeed до maxSpeed
   · currentSpeed += accel_amount
2. Остановка:
   · Если клавиши не нажаты и есть скорость
   · Скорость уменьшается до нуля
   · currentSpeed -= drag_amount
3. Занос:
   · Если нажата клавиша противоположная движению
   · Скорость быстро уменьшается
   · currentSpeed -= skid_amount
4. Полная остановка:
   · Если нет ввода и скорость равна нулю
   · Ничего не делает, просто для ясности

---

jump_func(delta: float)

Обрабатывает механику прыжка.

Параметры:

· delta-время между кадрами

Логика:

1. Начало прыжка:
   · При нажатии кнопки прыжка и jumpActionCount == 0
   · velocity.y становится равным jumpVel
   · jumpActionCount увеличивается до 1
2. Удержание прыжка:
   · Если уже в прыжке и кнопка зажата
   · Добавляется небольшая скорость вверх
   · Позволяет прыгать выше при удержании

---

gravity_func(delta: float)

Применяет гравитацию к персонажу.

Параметры:

· delta-время между кадрами

Логика:

· Если персонаж в воздухе → добавляется гравитация к скорости
· gravity = gravAcc * gravVec
· Если персонаж на земле → гравитация компенсируется «силой сопротивления поверхности»

---

sprite_flip()

Поворачивает спрайт в сторону движения.

Логика:

· Если velocity.x не равен нулю
· _facing = sign(velocity.x) (1 или -1)
· Масштаб спрайта по X умножается на _facing (зеркалирование)

---

Формулы расчёта

Величина Формула
Ускорение (maxSpeed - minSpeed) * delta / accTime
Торможение (maxSpeed - 0) * delta / dragTime
Занос (maxSpeed - 0) * delta / skidTime
Текущая скорость (движение) min(maxSpeed, max(minSpeed, currentSpeed + accel))
Текущая скорость (остановка) max(0, currentSpeed - drag_amount)

---

Состояния персонажа

Состояние Условие
На земле is_on_floor() == true
В прыжке jumpActionCount == 1
Падает fallState == true
Движется вправо velocity.x > 0
Движется влево velocity.x < 0
Стоит velocity.x == 0 и dir == 0

---

Управление

Клавиша Действие
A / ← - Движение влево
D / → - Движение вправо
Пробел - Прыжок (удержание = выше прыжок)
